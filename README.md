# Rangkita Digital

Rangkita adalah platform digital yang merangkai berbagai kebutuhan dalam satu tempat, mulai dari undangan nikahan online, latihan soal CPNS, produk digital, hingga artikel informatif.

## Fitur Saat Ini

- Landing page Rangkita
- Katalog produk digital
- Detail produk menggunakan slug
- Artikel dan detail artikel
- Katalog template undangan
- Preview undangan berdasarkan template
- Tema template dinamis
- Countdown acara
- Form kontak menuju WhatsApp
- Tampilan responsif

## Teknologi

- Laravel
- Blade Template
- PHP
- CSS
- JavaScript
